# Warcraft 3 Frozen Throne Mod Documentation

Welcome to the official documentation for the Warcraft 3 Frozen Throne mod for Half-Life. This documentation covers everything you need to know about installing, configuring, and using the mod.

## Current Version

The current stable version is 3.x. This documentation primarily covers the latest version, though some historical information about previous versions may be included for reference.

We welcome contributions to both the mod and its documentation! If you'd like to contribute:

2. Make your changes
